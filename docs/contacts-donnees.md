## 1. Auvergne-Rhône-Alpes Tourisme (Geotrek)

**Objet :** Réutilisation des circuits vélo Geotrek dans une application mobile gratuite

Bonjour,

Je développe à titre personnel une application mobile **gratuite** (Android, puis iOS) qui aide les cyclistes à trouver les circuits vélo **officiels** autour d'eux : route, VTT, gravel et VAE. L'application affiche la carte du tracé, le profil altimétrique, les informations pratiques, et propose le téléchargement du fichier GPX.

J'ai constaté que l'instance Geotrek d'Auvergne-Rhône-Alpes Tourisme (`geotrek.auvergnerhonealpes-tourisme.com/api/v2/`) publie ces circuits via son API publique. Avant toute mise en ligne, je souhaiterais m'assurer de pouvoir les réutiliser :

1. Sous quelle licence ces données sont-elles diffusées (par exemple Licence Ouverte Etalab 2.0) ?
2. Quelles mentions d'attribution attendez-vous (Auvergne-Rhône-Alpes Tourisme, organisme producteur de chaque circuit, auteurs des photos) ?
3. Les photos et les fichiers GPX sont-ils couverts par la même licence ?
4. Avez-vous des recommandations d'usage de l'API (fréquence de synchronisation, limite de requêtes) ?

Chaque fiche citera l'organisme producteur et renverra vers la page d'origine du circuit. L'application est sans publicité et sans collecte de données personnelles.

Je reste disponible pour vous présenter le projet.

## 2. FFVélo — Véloenfrance

**À :** veloenfrance@ffvelo.fr
**Objet :** Partenariat : circuits Véloenfrance dans une application mobile gratuite

Bonjour,

Je développe à titre personnel une application mobile **gratuite** qui recense les circuits vélo **officiels** en France (route, VTT, gravel, VAE), avec carte, profil altimétrique et téléchargement GPX.

Les circuits de Véloenfrance, et en particulier les **randonnées permanentes** labellisées, correspondent exactement à ce que je souhaite proposer aux cyclistes. Je n'ai pas trouvé d'API ni d'export public, d'où ma prise de contact :

1. Serait-il possible d'accéder aux circuits (tracés GPX et informations descriptives) via une API ou un export régulier ?
2. Sous quelles conditions (licence, mentions, liens vers Véloenfrance ou vers les clubs organisateurs) ?
3. Seriez-vous intéressés par un partenariat, par exemple un renvoi systématique vers la fiche Véloenfrance et l'inscription aux randonnées permanentes ?

L'application est sans publicité ni collecte de données personnelles. Ce serait un plaisir d'échanger avec vous à ce sujet.

Bien cordialement,
[Prénom Nom]
